# StepWay 0.1

Первая тестовая версия Android-приложения для прогулок.

## Уже работает
- тёмный интерфейс StepWay;
- Старт / Пауза / Продолжить / Стоп;
- таймер прогулки;
- подсчёт шагов через Android TYPE_STEP_COUNTER;
- приблизительные расстояние и калории;
- итоговый экран прогулки;
- заглушка под будущую Google Maps.

## Запуск
1. Откройте папку StepWay в Android Studio.
2. Дождитесь Gradle Sync.
3. Запустите на реальном Android-телефоне (датчик шагов в эмуляторе обычно отсутствует).
4. Разрешите доступ к физической активности.

На следующем этапе: foreground service, GPS, реальная дистанция, история прогулок и Google Maps.
